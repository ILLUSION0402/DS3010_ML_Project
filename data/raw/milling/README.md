# Milling raw data

Place the extracted NASA PCoE Milling dataset here:

```text
mill.mat
Readme.pdf   # optional reference copy
```

Expected path for the run command: `data/raw/milling/mill.mat`.

Do not commit `mill.mat` to the repository unless the team explicitly decides to
store large raw datasets in Git/LFS. Keep the original download/archive outside
Git or use the team's approved data storage. The pipeline does not modify the
raw file.
